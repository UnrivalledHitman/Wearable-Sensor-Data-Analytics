# M3 progress

Started 2026-10-03. LOSO over 15 subjects, clean data pipeline, per-subject
normalisation, single seed unless stated.

## What was built

- **SeqNet**, one configurable model family (`Code/pipeline/model.py`): conv
  blocks that can halve the sequence, an optional GRU or LSTM (one or two
  directions), optional self-attention, mean pooling and a small classifier.
  The original paper model is kept unchanged for the legacy configs.
- **Tasks** in the deep pipeline: binary (stress vs baseline + amusement),
  three-class and four-class, set by `train.task`.
- **Subject-wise validation** (`train.validation = "subjects"`): early stopping
  on two whole held-out training subjects instead of random overlapping
  windows, which leaked into validation before.
- **Seeds**: `run --seeds 42 43 44 45 46` repeats each config per seed.
- **Cost recording** per fold: parameters, seconds per epoch, epochs, peak GPU
  memory.
- **32 configs** in `Code/configs/m3/`, generated by `make_configs.py`.

| Group | Configs | Question |

## Design check: the downsampling front-end

BiGRU + attention, four-class, 10 s windows:

| Front-end | Steps into the GRU | Accuracy | Macro-F1 | Seconds per epoch | Peak GPU memory |
| --- | --- | --- | --- | --- | --- |
| Two conv layers, no downsampling | 320 | 0.757 ± 0.124 | 0.652 | 2.2 | 697 MB |
| Four conv blocks, 16x downsampling | 20 | 0.740 ± 0.105 | 0.635 | 0.8 | 148 MB |

Downsampling is 2.75x faster per epoch and uses 4.7x less GPU memory. The
accuracy difference (-1.7 points) is not significant (paired t-test p = 0.53,
Wilcoxon p = 0.60, 15 subjects), but this is one seed; the seeded runs will
settle it. The main grid uses the downsampled front-end.

## First 60 s result

Proposed model, four-class, 60 s windows: accuracy 0.736 ± 0.125, macro-F1
0.646, kappa 0.64, amusement F1 0.21. Cost: 0.8 s per epoch, 564 MB peak GPU
memory, about 11 epochs before early stopping.

Two early signals, both to be confirmed over seeds:

- Unlike the hand-crafted features (M2), the deep model does **not** gain from
  60 s windows over 10 s.
- The gap to the feature baseline is large: 0.74 against 0.91 (AdaBoost on
  chest features, four-class, M2). Subject-wise validation also costs the deep
  model two training subjects per fold; that is the honest setup but is worth
  noting when comparing with M2, which has no validation split.

## Running the grid

About 5-6 minutes per 15-fold run on the RTX 4060 laptop GPU (loading data
for each fold takes longer than training). The full grid is 32 configs x 5
seeds = 160 runs, roughly 15-16 hours. It is resumable.

```bash
python Code/run_pipeline.py run --config Code/configs/m3/b_*.toml --seeds 42 43 44 45 46 --resume
python Code/run_pipeline.py run --config Code/configs/m3/c_*.toml Code/configs/m3/d_*.toml --seeds 42 43 44 45 46 --resume
python Code/run_pipeline.py run --config Code/configs/m3/a_*.toml --seeds 42 43 44 45 46 --resume
```

Runs with `--seeds` write to `<out_dir>_seed<N>`, so the single-seed runs above
(in folders without a seed suffix) are not reused; seed 42 is retrained once.
